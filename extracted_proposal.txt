Abstract
The event management industry continues to grow as individuals, businesses, and organizations increasingly organize weddings, corporate events, conferences, birthdays, and outdoor activities. However, the process of finding and booking event venues, event planners, and service providers remains fragmented across multiple unverified platforms, leading to fraud, poor communication, inefficient booking processes, and financial losses. This proposal presents the design and development, a web-based Event Planning and Space Booking Platform that will provide a centralized solution for discovering and booking verified event venues, event planners, and event service providers.
The primary objective of the project will be to develop a secure, intelligent, and user-friendly platform that simplifies event planning while improving transparency, trust, and booking efficiency. The system will incorporate machine learning techniques to generate personalized recommendations based on user preferences and detect suspicious booking activities to minimize fraud.
The project will adopt the Agile software development methodology to support iterative development, continuous testing, and regular stakeholder feedback throughout the implementation process. The frontend will be developed using React with TypeScript, while the backend will be implemented using Django REST Framework and Python. PostgreSQL will be used as the database management system, and Scikit-learn will be used to develop the machine learning models.
The expected outcome will be a reliable and scalable web application that streamlines the event booking process, improves communication between customers and vendors, enhances security through vendor verification and fraud detection, and contributes to the digital transformation of event management services in Kenya.
Keywords: Event Planning, Event Booking System, React, TypeScript, Django REST Framework, PostgreSQL, Machine Learning, Fraud Detection, Recommendation System.

Chapter 1: Introduction
1.1 Background information
The event management industry continues to grow as individuals, businesses, and organizations increasingly organize weddings, corporate events, conferences, birthdays, and outdoor activities. In 2026, digital platforms play an important role in helping users discover services, compare options, and make bookings online. However, many event-related services remain fragmented across different websites and social media platforms, making it difficult for customers to find reliable venues, event planners, and service providers efficiently.
One of the major challenges faced by customers is the lack of a centralized and trustworthy platform where they can access verified event spaces and vendors. Many users rely on informal channels that may contain outdated information, unverified providers, or fraudulent listings. This often results in time-consuming searches, poor communication, and increased risks during the event planning process.
To address this gap, this project proposes the development of Event Planning and Space Booking Platform, a web-based platform that connects customers with verified event venues, event planners, and event service providers. The system will simplify the booking process, improve trust through vendor verification, and use machine-learning techniques to provide personalized recommendations and detect suspicious booking activities. By integrating these services into a single platform, Event Planning and Space Booking Platform aims to improve the efficiency, reliability, and overall experience of event planning.
1.2: Problem statement
Planning events such as weddings, corporate functions, birthdays, and outdoor activities often requires customers to search for venues, event planners, and service providers through multiple unverified channels, including social media platforms and personal referrals. This affects customers, venue owners, event planners, and service providers by increasing the risk of fraud, poor communication, double bookings, financial losses, and inefficient booking processes, which can negatively affect the success of events. According to Business Research Insights (2024), the continued growth of the global event management industry has increased the demand for secure and efficient digital booking solutions, highlighting the need for a centralized platform that connects users with verified vendors and event spaces while improving trust, communication, and booking efficiency.
1.3: Objectives of the project
1.3.1 General objectives
To develop a secure, intelligent, and user-friendly web-based platform that connects customers with verified event venues, event planners, and event service providers, thereby improving the efficiency, reliability, and transparency of the event booking process.
1.3.2 Specific objectives
To develop a centralized web-based platform that enables users to search, view, and book verified event venues, planners, and service providers by November 2026. 
To implement a vendor and venue verification system that verifies all registered vendors and venues before they are listed on the platform by November 2026. 
To collect, store, and analyze user, vendor, venue, and booking data to generate useful insights and support personalized recommendations by November 2026. 
iv. To integrate machine learning models for personalized venue and vendor recommendations and dynamic pricing based on user preferences, historical booking data, and venue characteristics by November 2026.
To reduce fraudulent booking activities by implementing machine learning-based fraud detection and administrator monitoring features by November 2026.
1.4 Scope 
The   Event Planning and Space Booking Platform will focus on developing a web-based system that enables users to search, compare, and book verified event venues, planners, and service providers. The system will collect and analyze relevant booking and user-interaction data to generate insights, provide personalized recommendations, support fraud detection and data-driven dynamic pricing of event venues. It will also provide user authentication, venue and vendor verification, booking management, and an administrative dashboard for managing platform activities. The project will primarily target users in Kenya and will exclude online payment processing and a native mobile application during the initial implementation.
1.5 Justification
The problem is important to solve because the current process of finding and booking event venues, planners, and service providers is often fragmented, time-consuming, and prone to fraud. Customers may experience financial losses, poor service delivery, and communication challenges when dealing with unverified vendors. By providing a centralized platform with verified listings, secure booking processes, and intelligent recommendations, Event Planning and Space Booking Platform improve trust, efficiency, and convenience for customers, venue owners, event planners, and service providers.

Chapter 2: Literature review
2.1 Introduction
This chapter reviews existing event booking and event management systems that are related to the proposed Event planning and space booking platform. The reviewed systems provide a basis for comparison by highlighting their strengths, limitations, and technologies used in managing event venues, planners, and service providers. The review also identifies gaps in current solutions and demonstrates how the proposed Event planning and space booking platform system addresses these limitations through a centralized, secure, and intelligent web-based platform.
2.2 Case Studies
2.2.1 Case Study 1: Eventbrite
Eventbrite is one of the world's leading online event management and ticketing platforms, allowing organizers to create, promote, and manage events while enabling users to register and purchase tickets online. The platform has simplified event organization by providing digital event listings and online registration.
Despite its effectiveness in ticketing and event promotion, Eventbrite primarily focuses on event registration and ticket sales rather than providing comprehensive event planning services. It does not offer integrated booking of event venues, event planners, photographers, caterers, decorators, or other event service providers through a single platform.
The proposed Event Planning and Space Booking Platform system extends beyond Eventbrite by providing a centralized platform where users can search for verified event venues, book event planners and service providers, receive personalized recommendations, and track booking requests while reducing the risks associated with fraudulent vendors.
2.2.2 Case Study 2: Cvent
Cvent is a cloud-based event management platform widely used for conferences, corporate meetings, and business events. The system provides venue sourcing, event registration, attendee management, and reporting tools that assist organizations in managing large-scale events efficiently.
Although Cvent offers powerful event management features, it is primarily designed for enterprise users and corporate organizations, making it less suitable for individuals and small businesses planning personal events such as weddings, birthdays, and outdoor celebrations. Additionally, many of its advanced features require paid subscriptions, limiting accessibility for many users.
Event Planning and Space Booking Platform aims to provide an affordable and user-friendly alternative by supporting both individuals and organizations while integrating verified vendors, booking management, and machine learning-powered recommendations into a single web-based platform.
2.2.3 Case Study 3: WeddingWire
Wedding Wire is an online marketplace that connects couples with wedding venues and wedding service providers, including photographers, caterers, decorators, and wedding planners. The platform allows users to browse vendor profiles, read reviews, and request quotations.
However, Wedding Wire mainly focuses on wedding-related services and does not fully support other types of events such as corporate functions, conferences, picnics, camping activities, birthday parties, and community events. Furthermore, it offers limited intelligent recommendation capabilities and does not incorporate machine-learning techniques for personalized recommendations or fraud detection.
The proposed Event Planning and Space Booking Platform addresses these limitations by supporting multiple event categories through a centralized booking system while integrating machine learning for personalized venue and vendor recommendations, fraud detection, and improved decision-making during the event planning process.
2.2.4 Case Study 4: AllEvents.in
AllEvents.in is an online event discovery platform that enables users to search for upcoming events, purchase tickets, and discover activities based on their location and interests. The platform supports event organizers by providing tools to publish and promote events to a wider audience.
Although AllEvents.in is effective for event discovery and promotion, it primarily focuses on listing events rather than providing a complete event planning solution. It does not offer integrated booking of verified event venues, event planners, photographers, caterers, decorators, or other event service providers. Additionally, the platform provides limited personalized recommendations and does not incorporate machine learning techniques for fraud detection or vendor verification.
The proposed Event Planning and Space Booking Platform will provide a centralized solution that enables users to search and book verified event venues, event planners, and service providers within a single platform. It will further integrate machine learning to generate personalized recommendations, detect fraudulent booking activities, and enhance the overall security, reliability, and efficiency of the event planning process.
2.3 The Gap
The reviewed systems demonstrate significant progress in digital event management but still present several limitations. Eventbrite mainly focuses on event registration and ticketing, Cvent primarily targets corporate events and enterprise users, WeddingWire is limited to wedding-related services, and AllEvents.in mainly supports event discovery rather than complete event planning. None of these systems provides a centralized platform that integrates verified event venues, event planners, and event service providers while incorporating machine learning for personalized recommendations and fraud detection.
The proposed Event Planning and Space Booking Platform seeks to address these gaps by providing a secure, intelligent, and centralized web-based solution. The system will enable users to discover and book verified venues and service providers, receive personalized recommendations based on their preferences, detect suspicious booking activities using machine learning, and improve communication between customers, vendors, and administrators, resulting in a more efficient and trustworthy event planning experience.

This chapter reviewed existing event booking and event management systems related to the proposed Event Planning and Space Booking Platform. It examined four case studies—Eventbrite, Cvent, Wedding Wire, and AllEvents.in—highlighting their features, strengths, and limitations. The chapter also identified the gaps in existing solutions, including the lack of a centralized platform, limited support for multiple event types, insufficient vendor verification, and the absence of machine learning-based recommendations and fraud detection. These findings provide the foundation for the proposed system, which aims to address these limitations through a secure, intelligent, and user-friendly web-based platform.
Chapter 3: Methodology
3.1 Chapter Introduction
This chapter describes the design and development approach for the proposed Event planning and space booking platform. It presents the system methodology, functional and non-functional requirements, system components, system architecture, database design, user interface design, development environment, and implementation process. The chapter also explains the technologies and tools that will be used, including React with TypeScript, Django REST Framework, PostgreSQL, and machine learning techniques, to develop a secure, intelligent, and user-friendly web-based event booking platform.
3.2 Project methodology
The development of the Event Planning and Space Booking Platform will adopt the Agile software development methodology. Agile is suitable for this project because it supports iterative development, continuous testing, and regular feedback throughout the software development life cycle. The project will be divided into small development cycles, where each sprint will focus on implementing and testing specific system features before progressing to the next phase.
The project will begin with requirements gathering and analysis, where functional and non-functional requirements will be identified through literature review, analysis of existing event booking systems, and stakeholder needs. This will be followed by the system design phase, which will include designing the system architecture, database structure, user interfaces, APIs, and machine learning components.
During the development phase, the frontend will be implemented using React with TypeScript, while the backend will be developed using Django REST Framework and Python. PostgreSQL will be used as the database management system, and Scikit-learn will be used to implement machine learning models for personalized recommendations, fraud detection, and dynamic pricing. The collected user, venue, vendor, booking, and feedback data will be cleaned, analyzed, and prepared for training and testing the machine learning models. The analyzed data will support personalized recommendations, fraud detection, and dynamic pricing. Historical booking and venue data will be used to train the Random Forest Regressor for estimating appropriate venue prices based on factors such as booking lead time, seasonality, venue utilization, and competitor pricing.
The system will undergo unit testing using Jest for the React frontend and PyTest for the Django backend. Integration testing will be conducted to verify communication between the frontend, backend, database, and machine learning module, while User Acceptance Testing (UAT) will be carried out to ensure that the system meets user requirements. After successful testing, the system will be deployed and continuously monitored for maintenance and future improvements
3.3 Requirement analysis
Requirement analysis was conducted to identify the functional and non-functional requirements of the proposed Event planning and space booking platform. The requirements were gathered through a review of related literature, existing event management systems, and user needs analysis. The functional requirements include user registration, vendor verification, booking management, machine learning-based recommendations, fraud detection, and an administrative dashboard, while the non-functional requirements include security, performance, usability, scalability, reliability, and compatibility. These requirements provide the foundation for designing and developing a secure, efficient, and user-friendly web-based event booking platform. Data Collection and Analysis Module: the system will collect data from user interactions, searches, bookings, ratings, vendor profiles, and venue listings. The data will be stored in PostgreSQL and analyzed to identify user preferences, booking patterns, and suspicious activities.
